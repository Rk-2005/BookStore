# Book Store Application

## 📌 Overview
This is a **MERN Stack** project that serves as an online **Book Store** where users can browse books, view free courses, and manage authentication (signup & login). The project utilizes **React.js** for the frontend, **Node.js & Express.js** for the backend, and **MongoDB** as the database.

## 🚀 Features
### ✅ Frontend
- **Home Page** with an engaging banner and book list.
- **Free Book Section** with a slider showcasing free books.
- **Authentication System** (Signup & Login) with secure password hashing.
- **Dark Mode Support** for an enhanced user experience.
- **Responsive Design** using Tailwind CSS.

### ✅ Backend
- **User Authentication** with password hashing using **bcrypt.js**.
- **RESTful APIs** to fetch books and manage users.
- **MongoDB Integration** for storing books and user details.
- **CORS Handling** for seamless communication between frontend and backend.

## 🛠️ Technologies Used
### 📌 Frontend
- **React.js**
- **Tailwind CSS**
- **React Slick (for sliders)**

### 📌 Backend
- **Node.js & Express.js**
- **MongoDB & Mongoose**
- **bcrypt.js** (for password encryption)
- **dotenv** (for managing environment variables)

## 🔥 Setup & Installation
### 1️⃣ Clone the Repository
```sh
git clone https://github.com/RK-2005/book-store.git
cd book-store
```

### 2️⃣ Install Dependencies
#### 📌 Frontend
```sh
cd frontend
npm install
```

#### 📌 Backend
```sh
cd backend
npm install
```

### 3️⃣ Configure Environment Variables
Create a `.env` file in the **backend** folder and add:
```env
MONGO_URI=your_mongodb_connection_string
PORT=5000
```

### 4️⃣ Run the Project
#### 📌 Start Backend Server
```sh
cd backend
npm start
```

#### 📌 Start Frontend
```sh
cd frontend
npm start
```
